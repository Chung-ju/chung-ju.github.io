abstract: >-
  Cloud-hosted Large Language Models (LLMs) raise serious privacy concerns, as clients' prompts and responses can be exposed to service providers, while existing solutions fail to simultaneously deliver privacy, model performance, and computational efficiency. We propose Talaria, a confidential inference framework that splits the LLM pipeline so that sensitive, weight-independent operations run inside a client-controlled Confidential Virtual Machine (CVM), while weight-dependent computations are offloaded to cloud GPUs. Communication between these components is protected by our Reversible Masked Outsourcing (ReMO) protocol, which employs hybrid masking to reversibly obscure intermediate data before outsourcing. Evaluations show that Talaria defends against state-of-the-art token inference attacks, reducing token reconstruction accuracy from over 97.5% to an average of 1.34%, while producing outputs identical to the original model with minimal impact on efficiency and scalability. To the best of our knowledge, this is the first work that ensures clients' prompts and responses remain inaccessible to the cloud while also safeguarding model privacy, performance, and efficiency.
